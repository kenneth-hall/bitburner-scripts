# Script library (`src/`)

**Read this before hand-doing a network/scan/path/aug/rep/backdoor task, or before writing a
new one-off — a script probably already exists.** (Trigger case: connecting to `w0r1d_d43m0n`
is `connect.js`, not a hand-walked `connect` chain.) Every script's own header comment is the
authoritative detail; this is the index. `run <name>.js` unless noted "imported".

## Read-only diagnostics & probes (run by hand)

⚠️ **Mostly read-only, but not entirely** — a few entries below mutate game state and are flagged
**Mutating** inline (`switchbbcity.js`, `setratchetmode.js`). Exactly one is **🔴 IRREVERSIBLE**
(`raidtest.js`). Check the flag before running anything here unattended; only the unflagged rows are
covered by the standing read-only probe grant in `CLAUDE.md`.
